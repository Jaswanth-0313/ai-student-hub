## 📱 How to Access Tools from Your App

### **Method 1: From Tools Page (Best Way)**
1. Open: https://ai-student-hub-cwql.onrender.com
2. Login with your account
3. Click **"Tools"** in navbar
4. Find the tool you want
5. If not connected:
   - Click **"✚ Connect"**
   - Enter your credential
   - Click **"✓ Connect"**
6. Once connected, click **"🔗 Open"** button
7. Opens the website in a new tab!

### **Method 2: Go Directly to Website**
Just open the website URL directly (see table above):
- https://chat.openai.com
- https://github.com
- etc.

### **Method 3: From Dashboard**
1. Login
2. Click **"Dashboard"**
3. See your connected tools listed
4. Click any connected tool to go there

## 🔐 Keep Your Credentials Safe

When connecting tools:

- ✅ Use strong API keys
- ✅ Don't share keys with anyone
- ✅ Regenerate if you think it's compromised
